    4.1 Novyxs, un chatbot IA pour les entreprises

    MODE = PERSO · dirigé par moi, codé avec l'IA
    EN CLAIR Un assistant qui répond aux questions des clients sur le site d'un commerce, 24 h sur 24, à partir des vraies infos du commerce. Il ne raconte pas n'importe quoi : s'il ne sait pas, il le dit.

    Comment ça marche : l'entreprise a deux façons de nourrir son chatbot. Elle peut écrire elle-même ses questions et réponses, qui passent toujours en priorité. Et elle peut donner l'adresse de son site : mon programme le lit, le découpe en petits morceaux et garde les plus utiles pour chaque question. L'IA (Gemini) répond ensuite uniquement avec ces informations.

    L'entreprise a aussi un tableau de bord pour voir les conversations et les avis des clients 👍/👎. Le chatbot est en ligne : c'est lui qui répond dans la bulle 💬 en bas à droite de cette page.

    Node.js · Express 5 · Cheerio · Gemini · JSONL · JS

    4.2 Traducteur Quenya → Tengwar

    MODE = UQAM · 100 % codé par moi
    EN CLAIR Tu tapes un mot en elfique (la langue inventée par Tolkien dans Le Seigneur des anneaux) et le programme l'écrit avec l'alphabet elfique, lettre par lettre.

    Un travail pratique du cours de Programmation II, écrit en Java. Le programme reconnaît les 51 lettres de l'alphabet et repère les erreurs : un mot qui n'est pas de l'elfique est refusé.

    La démo est la copie exacte de mon programme, refaite pour le navigateur. Essaie hello pour voir l'erreur.

    Java · Enum · Exceptions · LaTeX

    4.3 Programmer au plus près du processeur

    MODE = UQAM · 100 % codé par moi
    EN CLAIR L'assembleur, c'est le langage le plus proche de la machine : on donne au processeur ses instructions une par une. C'est difficile, mais ça permet de comprendre comment un ordinateur fonctionne vraiment.

    Dans ce cours, j'ai écrit des programmes en assembleur RISC-V. La démo montre un classique, les tours de Hanoï : déplacer toute la pile de disques vers la droite, sans jamais poser un grand disque sur un petit. Clique sur « Lancer » pour voir l'ordinateur résoudre le casse-tête.

    RISC-V · RARS · Récursion · Pile

    4.4 Base de données d'une résidence pour aînés

    MODE = UQAM

    J'ai conçu toute la base de données d'une résidence pour personnes âgées : les résidents, les chambres, le personnel, les horaires, les paiements… 17 tableaux reliés entre eux, du plan sur papier jusqu'à la vraie base Oracle.

    Oracle · SQL Developer · MCD / MLD · Triggers
