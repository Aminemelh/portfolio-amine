Schéma fonctionnel

Le composant fonctionne selon deux modes, choisis par la broche MODE. En mode PERSO, l'unité de contrôle (moi) prend toutes les décisions : besoin, architecture, design, priorités, validation. Elle envoie ses consignes à une unité d'exécution externe (l'IA), qui écrit le code. En mode UQAM, l'unité d'exécution est déconnectée : tout le code est écrit à la main.

Circuits d'application

4.1 ChatBot IA pour petites entreprises

MODE = PERSO · dirigé par moi, codé avec l'IA

Plateforme multi-entreprises. Chaque entreprise donne l'URL de son site. Le serveur l'explore avec Cheerio, découpe le texte en extraits, garde les plus pertinents et les envoie à Gemini. Le modèle ne répond qu'à partir de ce contexte, et les infos « officielles » de l'entreprise passent avant le site.

Il comprend aussi un tableau de bord admin (re-scan, conversations, feedback 👍/👎), une limitation de débit, une validation des identifiants et un cache des réponses.

Node.js · Express 5 · Cheerio · Gemini · JSONL · JS

4.2 Traducteur Quenya → Tengwar

MODE = UQAM · 100 % codé par moi

TP de Programmation II en Java. Le programme translittère la langue elfique de Tolkien en commandes LaTeX Tengwar. Il repose sur un enum de 51 glyphes, une recherche gloutonne sur 3, puis 2, puis 1 caractère, l'ajout de TELCO ou ARA devant une voyelle initiale, et une exception PasDuQuenyaException.

La démo ci-contre est un port JavaScript fidèle de mon code Java.

Java · Enum · Exceptions · LaTeX

4.3 Programmation RISC-V

MODE = UQAM · 100 % codé par moi

Cours d'organisation des ordinateurs : pile et conventions d'appel, récursion, chaînes, tableaux, bits, virgule flottante, le tout dans RARS. La démo montre la récursion des tours de Hanoï, avec prologue/épilogue et sauvegarde de ra et s0–s3 sur la pile.

RISC-V · RARS · Récursion · Pile

4.4 Base de données d'une résidence pour aînés

MODE = UQAM

TP de bases de données : MCD, puis MLD, puis normalisation, puis schéma Oracle avec 17 tables, des séquences et des triggers pour générer les identifiants.

Oracle · SQL Developer · MCD / MLD · Triggers
